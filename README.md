# Cybertron Realm

Cybertron Realm is a Minecraft plugin that brings the iconic world of Cybertron from the Transformers universe to your server. This plugin is designed to enhance your Minecraft experience by adding unique features, events, and mechanics inspired by the Transformers franchise. It includes custom items, vehicles, and interactive elements that bring the spirit of Cybertron to life.

## Install

1. Download the latest release of Cybertron Realm from the [GitHub repository](https://github.com/EnderDevelopment/CybertronRealm).
2. Place the downloaded JAR file into the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. Once the server is running, use the command `/ciao` to receive a greeting from the plugin.
2. Explore the world to discover new items and features added by Cybertron Realm.
